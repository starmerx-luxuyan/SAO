# SAO v1.3.3 — Single UI + Internal GATE runline

## Public shape

Hosted ordinary play is intentionally small:

- one visual surface: `system_menu`;
- one mutation entry: `turn_execute`;
- one read-only action schema: `get_turn_contract`;
- state/catalog/vendor reads, save/import and explicit setup authority remain separate.

The old hosted `character_hud`, `boss_raid_hud`, `get_gm_observation`, `preview_gm_decision`, `execute_gm_decision`, `buy_from_vendor`, `sell_to_vendor`, `create_party` and `join_party` entry points are not registered by `server_public.py` in this overlay. Full/internal development composition may keep administrative and diagnostic tools.

## Fixed runline

For every action, including every element of a compound request:

1. fresh player observation;
2. fresh System Menu/player projection;
3. GATE grounding against that fresh player-visible state;
4. one authoritative mutation;
5. engine-owned stabilization;
6. fresh observation;
7. fresh System Menu projection.

`world_tick_ms`, `advance_encounter` and `process_timeline` are not public action inputs. Combat recovery/timeline settling is performed by the runtime.

## New ordinary-play adapters

The runline additionally absorbs direct gameplay mutations that previously lived outside the GM gate:

- NPC vendor buy/sell;
- player-to-player item transfer;
- self repair/blacksmith reinforcement/crafting/reclaim at a valid forge;
- skill equip/remove;
- party create/join.

The blacksmith actions in this overlay preserve the existing **player blacksmith** semantics. NPC blacksmith-as-a-service is a separate content/mechanics task and should be modeled explicitly rather than faked by passing an arbitrary smith proficiency from the model.

## Apply

Copy `src/`, `skills/` and `tests/` over the v1.3.2 tree, then bump `src/sao_mcp/__init__.py`, plugin manifest and release docs to `1.3.3`. Run the full repository test suite plus `tests/test_player_runline_v133.py` before deployment.

Do not deploy this overlay without a full-tree regression: it was prepared against the current v1.3.2 public contracts and source files that were inspectable from the hosted surface/repository, but this execution environment did not have a writable GitHub checkout.
