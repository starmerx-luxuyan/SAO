# v1.1.0 — Setup Authority & Custom Combat Styles

## Added

- explicit setup lifecycle (`begin -> configure -> finalize`) plus setup/admin character initialization tools;
- authoritative profile, Col, XP/location, skill proficiency and skill-slot configuration;
- setup-time item grants with real durability, reinforcement attempts, enhancements and equip state;
- public armor/generic-item catalog inspection;
- persistent campaign-local custom weapon, armor/shield, consumable, item, Skill and Sword Skill definitions;
- `proficiency_skill_id` for Sword Skills;
- declarative custom-mechanic bundles with composable conditions/effects;
- generic weapon-class → custom-skill proficiency routing;
- tracked per-level STR/AGI growth rules;
- proficiency-driven weapon reinforcement-attempt-cap rules;
- proficiency-driven normal attack damage/recovery rules;
- proficiency gain modifiers and threshold-driven Skill unlocks;
- custom teleport consumables recognized by the ordinary observation/travel runtime;
- grounded `engage_monster` player action backed by the living monster ecology;
- save schema `sao.aincrad.save.v4` with exact v3 migration.

## Authority boundary

Setup tools are intentionally separate from `execute_gm_decision`. The hosted surface accepts setup mutations only between `begin_campaign_setup` and `finalize_campaign_setup`; after finalization it cannot reopen them. The full internal surface retains `reopen_campaign_setup` for explicit maintenance.
