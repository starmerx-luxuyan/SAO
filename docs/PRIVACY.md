# SAO Aincrad Plugin Privacy Notice

Effective for v1.0.0.

SAO Aincrad is a fan-made, non-commercial MCP game runtime. The hosted service processes the MCP requests needed to execute the game actions a connected client asks for.

The project does not intentionally require or collect a real-world identity, login credential, payment information or advertising profile. Do not place passwords, API keys or other secrets in game/tool inputs.

Campaign state is held by the running service and can also be exported or imported explicitly through the save tools. The project does not promise permanent hosted storage; service restarts or deployments may reset in-memory state. Save payloads supplied through import tools are processed to restore the requested runtime state.

The hosting and network providers used to operate the service may process ordinary operational information such as request metadata, IP/network data and service logs according to their own policies.

This repository does not intentionally ship or collect copyrighted Sword Art Online source text, ripped databases, art, audio or game assets.

Questions or project issues can be filed through the repository at https://github.com/starmerx-luxuyan/SAO.
