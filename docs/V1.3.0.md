# SAO Aincrad v1.3.0 — Correctness Pass

v1.3.0 closes the Day 3 handoff against the authoritative runtime instead of adding another gameplay subsystem.

## Correctness fixes

- Floor 8 DKB/ALS state is no longer materialized when the server process starts. The Floor 8 emergency service loads without mutating current-world guild or named-player state, and only installs its clearing guilds after a valid Floor 8 trigger.
- Direct early calls to the canonical clearing-guild installer are rejected while Floor 8 is locked.
- Campaign Blueprint v1 can now materialize deterministic actor IDs, real friendships, anonymous population cohorts, named-player autonomous routines and an initial world-time target atomically.
- Named-player routines move real actors across real adjacent world-map edges on world-time boundaries. They do not fabricate off-screen combat victories or XP.
- GM observation treats accepted friendship, marriage and same-guild membership as legitimate identity knowledge.
- Custom-mechanics discovery now returns a Draft 2020-12 JSON Schema. Omitting a custom critical cap preserves the normal 0.25 cap instead of silently raising it to 1.0.
- Finalized-campaign amendments are clone-validated and committed atomically. `reopen_campaign_setup` remains an internal/admin tool; ordinary public setup cannot be reopened after finalization.
- Campaign setup state records amendment revision, amendment ID and amendment world time.
- System Menu quest rendering now reads the actual quest counter shape (`counters[objective_id]`) and the actual giver field.

## Super Luck

The campaign-local `超幸运` mechanic supports:

- absolute critical chance bonus with an explicit cap;
- per-recipient Col multiplier;
- non-key material drop chance multiplier;
- non-key material quantity multiplier.

Quest/key/unique-tagged material drops are not multiplied.

## Corrected Kageaki Day 3 preset

`presets/kageaki_day3.json` rebuilds the Day 3 campaign from runtime-native operations:

- 凑斗景明 at Lv.7 with 星辰剑 proficiency 238 and all twelve Star Sword techniques defined;
- six of those twelve techniques currently meet the Day 3 proficiency threshold;
- seven materialized female friends with accepted friendship edges and autonomous routes/activities;
- 9,792 anonymous population members plus eight named materialized players, representing a simulation baseline of 9,800 players before Day1–Day3 world consequences;
- no Lind/Kibaou Floor 8 combat profile and no DKB/ALS guild state in Day 3.

The population cohort numbers are simulation calibration, not claimed canon death counts.

`presets/kageaki_super_luck_amendment.json` applies the finalized-campaign Kageaki amendment without reopening setup. CI builds `SAO_Kageaki_Day3_v1.3.0.save.json` from the preset, applies the amendment, exports the native `sao.aincrad.save.v4` save and requires an exact export/import/export round trip.
